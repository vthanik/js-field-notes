# JS Field Notes

A self-built JavaScript course, written while going from R/Python (clinical
statistical programming) into vanilla JS, the DOM, and Shiny's custom-JS
layer (`shinychat`, custom Shiny inputs).

**Live site:** `index.html` — open directly, or serve via GitHub Pages
(Settings → Pages → Deploy from branch → main → / root).

## Contents

- `index.html` — the interactive course site (GitHub Pages serves this
  automatically). Primary, up-to-date resource; everything else is
  supplementary.
- `js-field-notes.pdf` — full print/offline export of the site (19 pages),
  all lessons expanded, for reading without a browser.
- `SOURCES.md` — every external reference consulted while building this
  (Impatient JS, Eloquent JS, MDN, Airbnb style guide, Granjon's Shiny book,
  web.dev). All course content itself is original — this is attribution,
  not a bibliography of copied text.
- `js-syllabus.md` — course syllabus / table of contents, checklist format.
- `lesson-01-variables-and-values.md`, `lesson-02-undefined-null-truthy-falsy.md`,
  `lesson-03-functions.md` — the earlier standalone lesson-file format,
  kept as-is; superseded by the site for anything written after Lesson 3.
